# 决策卡输出模板（Markdown 源）

> 本文件是 `/ceo-office` 决策卡（Decision Card）的 Markdown 源模板，由 agent 在产出决策卡前读取。
> 修改本文件即时生效，无需重新生成 SKILL.md。
> 产出时必须严格遵循字段结构与字段顺序，不自行增删字段。
> 决策卡只承载「当前最该批的一个 top-level 决策」； Continue Discussion / Economic Model Snapshot 轮次不产出。
> 同名 `.html` 是本卡的唯一可视化渲染，两文件内容必须逐字段一致。

# 决策卡 YYYY-MM-DD

- **状态**：待批准
- **决策点**：一句话说清要老板批什么（不超过 30 字）
- **建议**：批准 / 继续 / 暂停 / 缩小 / 转向 的具体动作（标注 mode：FOCUS / EXPANSION / HOLD / REDUCTION）
- **链路置信度**：High / Medium / Low / Unknown —— 一句话理由
- **依据**：不超过 3 条，每条一行，逐条标注 [事实] / [假设]
  1. [事实] …
  2. [假设] …
- **最致命的问题**：一行
- **翻案条件**：出现什么证据就改判（可验证、可观察，不写「视情况而定」）
- **选项**：
  - A.（推荐）……
  - B. ……
  - C. ……
- **关联**：project-memo-YYYY-MM-DD.md；无 memo 时写「无」

## 状态流转

- 状态取值：`待批准` / `已批准` / `已调整` / `已搁置`
- 收到老板批复后，原地更新本字段（含同名 html）；这是 dated-file 约定对决策卡的唯一例外
- 判断内容本身变化时，新建当日新卡，不改旧卡内容
